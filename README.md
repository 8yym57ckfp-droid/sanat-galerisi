# Sanat Atölyesi — Perihan Baktaş

GitHub Pages ile yayınlanmaya hazır tek sayfalı sanat galerisi sitesi.

## İçerik
- `index.html`: Tam site; stiller, JavaScript, fontlar ve görsel kaynaklar sayfaya gömülüdür.
- `sanat-galerisi-site.zip`: Aynı site ve kullanım notlarıyla indirilebilir paket.

Site statiktir; Java veya Python sunucusu gerektirmez. GitHub Pages için Settings → Pages bölümünden `main` dalını ve kök klasörü seçin.
